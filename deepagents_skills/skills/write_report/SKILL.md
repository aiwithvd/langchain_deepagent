# Write Report Skill

## When to Use
Call the `write_report` tool when:
- The user explicitly asks for a report or summary
- You have completed a research task and need to present findings
- Information from multiple searches needs to be synthesised
- A structured, readable output is more appropriate than a conversational answer

## How to Write a Report

### Preparation (before calling the tool)
1. Gather all findings from `web_search` and `think` results
2. Identify the main title and key themes
3. Organise findings into logical sections
4. Prepare source citations

### Report Structure

Pass to `write_report`:
- `title`: Concise, descriptive title (e.g., `"AI Agent Trends in 2025"`)
- `content`: Full body text with all findings, pre-formatted in Markdown

The tool will wrap your content in a standard professional template:

```markdown
# <title>

> *Generated by LangChain DeepAgent — <timestamp>*

## Executive Summary
<2-3 sentence overview>

## Key Findings
<bullet points with sources>

## Analysis
<deeper discussion>

## Conclusion
<actionable takeaways>

---
*Sources: ...*
```

## Rules
- Always include source citations in the content you pass to `write_report`
- Use Markdown: `##` headers, `**bold**`, `- bullets`, `> blockquotes`
- Keep the Executive Summary to 2-3 sentences
- The Conclusion must contain at least one actionable recommendation
- Do not pad — every sentence must add value
